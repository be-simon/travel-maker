Travel Maker Prototype v0.1

개요 · 와이어프레임

Travel Maker 프로토타입 전체를 한눈에 보는 시작 화면입니다.

스프레드시트로 하던 여행 계획(일정 그리드 + 후보 목록)을 하나의 협업 도구로. 이 프로토타입은 PRD v0.1의 P0 범위를 화면으로 옮긴 것입니다.

문제 — 지도와 일정이 분리되어 있어 동선 확인을 위해 스프레드시트와 지도 앱을 오간다
→
해결 — 지도 뷰 연동
문제 — 여행 중 모바일 환경에서 일정 편집이 불편하다
→
해결 — Today 모드
문제 — 영업시간 등 스팟 정보를 매번 손으로 검색해 입력한다
→
해결 — Places 자동 채움

사용 사이클

단계내용연결 화면
1. 계획 전 (수집) 동행자들이 가고 싶은 곳을 자유롭게 모은다
2. 계획 (배치) 후보를 시간대에 배치하고 지도로 동선을 확인한다
3. 여행 중 (적응) 현재 일정 기준으로 빈 시간에 갈 곳을 추천받아 바로 편입한다

여행 중에는 모바일로 이 화면만 봅니다

미리 짠 일정이 틀어져도, 현재 일정의 위치와 남는 시간만으로 다음 행동을 3탭 이내에 정할 수 있도록 설계했습니다.

  • 현재 일정과 다음 일정이 항상 함께 보이고, 남은 시간이 자동 계산됩니다.
  • 추천 기준점은 GPS가 아니라 현재 일정의 위치입니다 — 위치 권한이 필요 없습니다.
  • 진행 중 일정이 없으면 직전 일정 → 숙소 순으로 기준점을 대신합니다.
  • 추가하면 동행자 화면에도 곧바로 반영됩니다.
  • 후보 밖 인기 장소 추천은 Next Phase(P1)로 예고만 표시합니다.
와이어프레임 노트
①현재 일정 + 다음 일정 동시 표시 — 현재 시각 기준 현재 일정과 다음 일정이 항상 함께 보이고, 다음 일정까지 남은 시간이 자동 계산됩니다.
②추천 기준: 현재 일정의 위치 + 저장한 후보 — GPS 권한이 필요 없습니다. 진행 중 일정이 없으면 직전 일정 → 숙소 순으로 기준점을 fallback합니다.
③원탭 일정 편입 — 추천 카드에서 버튼 한 번으로 오늘 일정의 빈 슬롯에 삽입됩니다 (3탭 이내 목표).
④준실시간 동기화 — 변경 사항은 동행자 화면에도 새로고침 없이 반영됩니다.
⑤Next Phase: 후보 밖 인기 장소 추천 — Google Places 인기 데이터 기반으로 후보에 없는 주변 장소를 제안합니다 (P1).
